# TrustScore: Automated DPDP Compliance Auditor

TrustScore is an enterprise-grade scanning engine designed to audit web properties for compliance with India's **Digital Personal Data Protection (DPDP) Act 2023**.

## 🚀 Key Features
* **Automated Scanning:** Instantly analyzes DOM elements for privacy indicators.
* **TrustScore Algorithm:** Proprietary scoring based on Privacy Policies, Cookie Consent, and Grievance Officer visibility.
* **Risk Assessment:** Categorizes compliance levels from 'Low' to 'Critical Risk'.
* **FastAPI Backend:** High-performance asynchronous API for real-time auditing.

## 🛠️ Tech Stack
* **Backend:** Python, FastAPI, BeautifulSoup4
* **Server:** Gunicorn / Uvicorn
* **Compliance Framework:** Indian DPDP Act 2023

## 📊 Why it Matters
With penalties for non-compliance reaching up to **₹250 Crores**, TrustScore provides businesses with a primary defense line by identifying public-facing legal exposure.
